# Culebrilla

Juego de culebrilla para navegador y celular: come frutas, encadena superpoderes, muerde colas brillantes y conquista 12 mundos.

**Jugar:** https://cesardelossantosdr06-hue.github.io/culebrilla/

- Modos: Clásico Pro, Aventura (50 niveles) y Battle Royale.
- Controles: ratón o flechas/WASD en computadora; deslizar el dedo en el celular. Turbo con clic, Espacio o el botón ⚡.
- 6 idiomas: español, inglés, portugués, francés, alemán y japonés.
